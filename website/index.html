How The Online Web Architecture Works

Because Tally's internal HTTP server is locked to localhost:8080 on your local Windows PC, a public website cannot access it directly due to browser CORS/Same-Origin security policies. Our solution provides the best of both worlds:

🌐

Modern browser UI running on React / HTML5. Configure filters, select heads, view live logs.
Frontend (User Friendly)
REST API (HTTP / JSON)
⚡

Lightweight background service (35 KB) on your PC. Translates web requests into TDL XML queries.
Local Engine (localhost:5000)

Audit-Grade Capabilities

Engineered Specifically for CAs & Financial Auditors

Every detail is built to eliminate manual spreadsheet cleanup and deliver presentation-ready Excel workbooks.

➕➖

Pure Numeric Signed Net Amount

No more string manipulation! All "Dr" and "Cr" text strings are stripped from transaction amounts. Debits are positive floats (+), Credits are negative (-). Run instant =SUM() formulas and Pivot Tables directly.

📑

Active "Trial Balance Extract" Sheet

Replaces flat ledger lists with a full hierarchy (e.g. Indirect Expenses > Rent > Branch Rent). Automatically filters out zero-movement dormant ledgers, presenting only active accounts.

📁

Strictly 1 Master XLSX Workbook

Zero duplicate CSV files cluttering your folders. Generates exactly ONE clean, styled workbook containing Trial Balance Extract, Transaction Register, and Summary sheets.

🏢

Multi-Company Consolidation

Merge all member entities (e.g. Dua Associates 7 member branches) into a single folder and single sheet with Company as Column 1, perfectly structured for group audits.

⚡

High-Speed Fast Mode

Uses targeted XML data projection to cut payload size by over 85%, extracting tens of thousands of transactions in seconds without freezing Tally.

🛡️

100% Audit Integrity Filters

Automatically excludes Memorandum, Optional, Cancelled, and Deleted vouchers to ensure your extracted registers match the audited ledger balance to the exact paise.

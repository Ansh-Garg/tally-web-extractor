2
Unzip the Downloaded File
Extract the contents to any folder on your computer
  • 1
    Find tally-web-extension.zip in your Downloads folder (bottom of your browser or in C:\Users\YourName\Downloads).
  • 2
    Right-click on the file and choose "Extract All..." or "Extract Here".
  • 3
    A folder named tally-web-extension will appear. Remember where you extracted it — you'll need that folder path in the next step.
What your extracted folder should look like:
📁 tally-web-extension/
├── 📄 manifest.json
├── 📄 background.js
├── 📄 content.js
├── 📄 popup.html
├── 📄 popup.js
└── 📁 icons/
⚠️
Important: Do NOT delete this extracted folder after installing. Chrome reads the extension files from this folder every time you start the browser.

Load the Extension in Chrome/Edge
Enable Developer Mode and load your unzipped folder — takes 30 seconds
🌐 Google Chrome
🔷 Microsoft Edge
🦁 Brave
  • 1
    Click the button below to open the Chrome Extensions page (or type chrome://extensions in your address bar):
  • 2
    Find the "Developer mode" toggle in the top-right corner of the page. Turn it ON (it should turn blue).

    Click the "Load unpacked" button that appears on the top-left.

    A folder picker dialog will open. Navigate to the extracted folder and click "Select Folder".
